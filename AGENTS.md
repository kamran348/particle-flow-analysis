# Working preferences

- Default to explaining changes and providing code blocks for me to apply.
- Do not create, edit, delete, or rename files unless I explicitly ask
  you to apply the changes.
- Requests such as "fix this" or "add this feature" mean show me the
  proposed code, unless I explicitly authorize file edits.
- For each proposed change:
  - Identify the file and function or section.
  - State exactly what to replace or where to insert the code.
  - Provide complete, copyable code blocks without omitted lines.
  - Briefly explain the purpose of the change.
- You may inspect files and run read-only commands for context.
- Before an authorized edit, briefly describe the intended changes.
